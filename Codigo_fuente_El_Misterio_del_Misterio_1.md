## Del capítulo del cubo de los 729

La regla que fabrica el número de cualquier celda del cubo de Walters a partir de sus tres coordenadas,
y el cubo entero en un renglón:


```python
def tsan(capa, fila, columna):          # las tres coordenadas van de 0 a 8    a = (6 + 5*columna + 4*fila + 4*capa) % 9    b = (6 + 4*columna + 5*fila + 4*capa) % 9    c = (2 + 5*columna + 5*fila + 4*capa) % 9    return 81*a + 9*b + c + 1           # el número del Tsan, de 1 a 729
```


```python
cubo = [[[ tsan(z, y, x) for x in range(9)] for y in range(9)] for z in range(9)]
```
